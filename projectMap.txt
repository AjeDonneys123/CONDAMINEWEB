INDEX DÉTAILLÉ

- `.env`: Ce fichier contient les variables d'environnement sensibles nécessaires au fonctionnement de l'application, telles que l'URI de la base de données MongoDB et la clé API de Gemini. Il est essentiel de protéger ce fichier et de ne pas le commiter dans un dépôt public. Les valeurs sont masquées dans l'arbre pour des raisons de sécurité.

- `IAReadMe.md`: Ce document Markdown fournit des instructions spécifiques sur l'utilisation de l'IA Gemini 2.0 FLASH dans le cadre du projet Condamine. Il détaille notamment la convention à respecter pour la génération des fichiers `update.txt` utilisés par le script `apply.js`, incluant l'utilisation de balises `[[[ FILE: chemin ]]]` pour identifier les fichiers à mettre à jour.

- `INSTRUCTIONS_OAUTH.md`: Ce document Markdown détaille les étapes à suivre pour configurer l'authentification OAuth avec Google, notamment pour accéder aux photos du compte Condamine. Il aborde les problèmes courants comme le `redirect_uri_mismatch` et propose plusieurs options concrètes pour résoudre ces problèmes, allant de la correction de l'URI de redirection à l'utilisation de la délégation à l'échelle du domaine (Domain-wide delegation).

- `LOCKED_FILES.md`: Ce document Markdown répertorie les fichiers critiques du projet qui sont considérés comme stables et fonctionnels. Il est impératif de ne pas modifier ces fichiers sans une autorisation explicite, car ils constituent la base du fonctionnement de l'application, notamment les routes d'authentification, la logique des jeux et les composants d'interface utilisateur clés.

- `apply.js`: Ce script Node.js applique les mises à jour du code à partir d'un fichier nommé `update.txt`. Il lit les instructions dans ce fichier, identifie les fichiers à modifier ou les logs à ajouter à l'historique, puis effectue les changements nécessaires. Il gère également la rotation de l'historique, en conservant les logs importants de manière permanente et les logs normaux sur une période limitée (10 derniers).

- `client/README.md`: Ce document Markdown fournit des informations générales sur le projet client React + Vite. Il explique que ce modèle fournit une configuration minimale pour faire fonctionner React dans Vite avec HMR et quelques règles ESLint. Il mentionne également deux plugins officiels disponibles: `@vitejs/plugin-react` et `@vitejs/plugin-react-swc`.

- `client/index.html`: Ce fichier HTML est le point d'entrée de l'application client React. Il contient la structure HTML de base, y compris le conteneur racine (`<div id="root"></div>`) où l'application React sera rendue. Il inclut également une balise `<script>` qui charge le fichier `main.jsx` pour démarrer l'application.

- `client/package.json`: Ce fichier JSON contient les métadonnées du projet client, y compris son nom, sa version, son type (module) et ses scripts. Il liste également les dépendances du projet (bibliothèques React, React DOM, React Router DOM) et les dépendances de développement (outils comme Vite, ESLint, Autoprefixer, Tailwind CSS).

- `client/src/App.css`: Ce fichier CSS contient les styles globaux de l'application client, notamment la mise en page de base, les styles pour le bouton de signalement de bug et la modale de bug. Il définit également des animations et des transitions pour améliorer l'expérience utilisateur. Le fichier utilise une approche de conception "mobile-first" avec des requêtes média pour adapter l'interface aux différentes tailles d'écran.

- `client/src/App.jsx`: Ce composant React est le point d'entrée de l'application front-end. Il gère l'état de l'utilisateur (connecté ou non), affiche le composant de connexion si l'utilisateur n'est pas connecté, et affiche soit la page professeur (si l'utilisateur a l'ID "prof"), soit la page élève. Il inclut aussi la logique de gestion des erreurs, en envoyant les erreurs au serveur pour analyse par l'IA.

- `client/src/features/auth/Login.css`: Ce fichier CSS contient les styles spécifiques au composant de connexion. Il définit l'apparence du formulaire de connexion, y compris le titre, les champs de saisie, le bouton de soumission et les différents états (focus, hover, disabled). Le fichier utilise des variables CSS pour faciliter la personnalisation et la maintenance du style.

- `client/src/features/auth/Login.jsx`: Ce composant React affiche le formulaire de connexion pour les élèves et les professeurs. Il gère l'état local des champs de saisie (prénom, nom, classe, mot de passe) et la logique d'authentification. Il communique avec le serveur via une requête POST pour vérifier les informations d'identification et rediriger l'utilisateur vers la page appropriée en cas de succès.

- `client/src/features/eleve/ElevePage.css`: Ce fichier CSS contient les styles spécifiques à la page élève, utilisant un thème rose clair pour le fond et des transitions douces. Il définit la mise en page générale et l'animation d'apparition des éléments. L'utilisation du rose vise à créer une atmosphère plus accueillante et adaptée aux élèves.

- `client/src/features/eleve/ElevePage.jsx`: Ce composant React gère l'interface principale pour les élèves. Il affiche l'en-tête de l'élève, les onglets de navigation (devoirs, français, jeux) et le contenu correspondant à l'onglet sélectionné. Il utilise des états locaux pour gérer l'onglet actif et passer les informations nécessaires aux composants enfants.

- `client/src/features/eleve/components/DashboardFolder.jsx`: Ce composant React affiche les devoirs et les jeux organisés par chapitre, dans une interface de type "dossier". Il utilise un état local pour gérer l'ouverture et la fermeture des chapitres, et récupère les données des chapitres et des éléments (devoirs ou jeux) via des props. Il filtre également les éléments en fonction des élèves ciblés et gère l'affichage des archives.

- `client/src/features/eleve/components/EleveHeader.css`: Ce fichier CSS contient les styles spécifiques à l'en-tête de l'interface élève. Il définit l'apparence de la barre supérieure, du nom de marque, du bouton de retour au profil professeur (si l'utilisateur est un élève de test), de la zone utilisateur et des onglets de navigation. Le fichier utilise un thème rose magenta pour correspondre au style global de l'interface élève.

- `client/src/features/eleve/components/EleveHeader.jsx`: Ce composant React affiche l'en-tête de l'interface élève, y compris le nom de marque, le bouton de retour au profil professeur (si l'utilisateur est un élève de test), la zone utilisateur (nom et classe de l'élève) et les onglets de navigation (devoirs, français, jeux). Il utilise des props pour recevoir les informations de l'utilisateur, les gestionnaires d'événements et l'onglet actif
